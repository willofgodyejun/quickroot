# 길찾기 3사 비교 (navi-compare)

네이버지도 · 카카오맵 · 티맵의 자동차 길찾기 결과(소요시간, 거리, 통행료, 정체 현황, 주요 도로)를 한 화면에서 비교합니다.

| 앱 | 상태 | 사용 API |
|---|---|---|
| 카카오맵 | 연동됨 | 카카오 Local(장소 검색) + 카카오모빌리티 Directions |
| 네이버지도 | 샘플 값 | (다음 단계) 네이버 클라우드 Maps Directions |
| 티맵 | 샘플 값 | (다음 단계) TMAP 경로안내 API |

API 키는 `server.js`에만 두고, 브라우저는 `/api/*`만 호출합니다. 키가 화면 코드에 노출되지 않아요.

## 실행

Node.js 18 이상이 필요합니다. 외부 패키지는 없어요.

```bash
cp .env.example .env      # 키 입력
npm start                 # http://localhost:3000
npm test                  # 응답 변환 테스트
```

## 카카오 키 발급

1. [카카오 디벨로퍼스](https://developers.kakao.com) → 내 애플리케이션 → 애플리케이션 추가
2. 앱 설정의 앱 키에서 **REST API 키**를 복사해 `.env`의 `KAKAO_REST_API_KEY`에 넣기
3. 앱의 **카카오맵 사용 설정을 활성화** (꺼져 있으면 장소 검색이 `OPEN_MAP_AND_LOCAL` 권한 오류로 막혀요)

자동차 길찾기는 비상업적 용도라면 기본 무료 쿼터 안에서 별도 제휴 없이 쓸 수 있습니다. 서비스로 운영할 계획이면 카카오모빌리티에 이용 조건을 확인하세요.

## 동작 방식

- 출발 시각이 현재 ±5분이면 실시간 길찾기(`/v1/directions`), 그 외에는 미래 시각 길찾기(`/v1/future/directions`)를 씁니다. 이미 지난 시각을 고르면 다음 날 같은 시각으로 계산해요.
- 카카오 `traffic_state`는 4 → 원활, 3·2 → 서행, 1·6 → 정체, 0 → 정보 없음으로 묶어 표시합니다.
- 정체 띠는 도로 구간 길이 비율 그대로 그리고, 주요 도로는 같은 이름의 연속 구간을 합친 뒤 긴 순서 상위 6개를 경로 순서대로 보여줍니다.
- 카카오 장소 검색으로 얻은 실제 좌표를 샘플 카드 계산에도 써서, 연동 전 앱도 거리 규모는 비슷하게 맞춰집니다.
